# Hotel Booking Analysis Dashboard

## Project Overview

This project explores hotel booking data using Microsoft Excel to analyze booking trends, cancellations, revenue, payment risk, and lead time.

## Objectives

- Analyze monthly booking trends.
- Calculate and explore booking cancellation rates.
- Calculate lead time and categorize bookings by payment risk.
- Compare booking patterns across hotel types and guest types.

## Tools & Skills

- Microsoft Excel
- PivotTables and PivotCharts
- KPI calculations
- Data categorization and analysis
- Interactive dashboards and slicers

## Dashboard Preview

The dashboard presents key booking metrics and visualizations, including monthly bookings, booking status, payment risk, and lead-time categories.

## Key Findings

- Total bookings: approximately 119.2K
- Total revenue: approximately $42.7M
- Cancellation rate: approximately 37%
